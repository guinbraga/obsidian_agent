Building the CLI Application

Excellent choice! Turning a collection of scripts into a unified CLI (Command Line Interface) application is the hallmark of a mature project. It makes your tools vastly easier to use.

In this lesson, we will use Python's built-in argparse module to create a single entrypoint (cli.py) that can route commands to either your LangGraph agent or your ingestion pipeline.

Step 1: Refactoring the Agent Script

Currently, your run_react_agent.py script runs the graph stream directly in its if __name__ == "__main__": block. To use it in a CLI, we need to wrap that execution in a callable function.

  1. Open run_react_agent.py.
  2. Above the if __name__ == "__main__": block, add a new function: 
    def run_agent(query: str):
    """Executes the agent graph with the given query and prints the output."""
    print(f"Asking Agent: '{query}'\n")
    events = graph.stream({"messages": [{"role": "user", "content": query}]})
    for event in events:
        for node_name, state in event.items():
            print(f"\n=== Node Completed: {node_name} ===")
            if "messages" in state:
                last_msg = state["messages"][-1]
                content = last_msg.content if last_msg.content else str(last_msg.tool_calls)
                print(f"[{last_msg.type.upper()}]: {content[:500]}")
  3. (Optional) You can now replace the contents of your if __name__ == "__main__": block with just a call to run_agent("Your test query").

Step 2: Introduction to argparse Subparsers

argparse is incredibly powerful. When you have multiple commands (like git commit vs git push), you use subparsers. Here, we want two commands:

  • python cli.py ask "My question"
  • python cli.py ingest data/my_file.pdf

Step 3: Creating cli.py

Create a new file in your project root named cli.py. This will be the brain of your command line interface. Paste the following code:

import argparse
import sys

# Import our underlying functions
from run_react_agent import run_agent
from src.ingestion.pipeline import run_pipeline

def main():
    # 1. Create the top-level parser
    parser = argparse.ArgumentParser(description="Obsidian Agent CLI")
    
    # 2. Create subparsers for the commands
    subparsers = parser.add_subparsers(dest="command", help="Available commands")
    subparsers.required = True # Force the user to choose a command
    
    # 3. 'ask' command
    ask_parser = subparsers.add_parser("ask", help="Ask the agent a question")
    ask_parser.add_argument("query", type=str, help="The prompt to send to the agent")
    
    # 4. 'ingest' command
    ingest_parser = subparsers.add_parser("ingest", help="Ingest a new document into pgvector")
    ingest_parser.add_argument("filepath", type=str, help="Path to the PDF or Markdown file")
    
    # Parse the arguments
    args = parser.parse_args()
    
    # Route execution based on the chosen command
    if args.command == "ask":
        run_agent(args.query)
    elif args.command == "ingest":
        print(f"Starting ingestion for: {args.filepath}")
        run_pipeline(args.filepath)
        print("Ingestion complete!")

if __name__ == "__main__":
    main()
