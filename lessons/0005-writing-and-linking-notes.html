Writing and Linking Notes

Spot on! Your summary of defensive programming was perfect. Now that our agent can read Obsidian notes, it's time to give it the power to write and link them.

In this lesson, we will create a tool to append content (and wiki-links) to an existing note, or create a new note if it doesn't exist.

Writing with Pathlib

Just as reading with `pathlib` was easy, writing is equally elegant. We can use the open method with append mode ("a") to safely add content to a note.

file_path = VAULT_DIR / "MyNote.md"

# Append content, creating the file if it doesn't exist
with file_path.open("a", encoding="utf-8") as f:
    f.write("\n\nThis is new content appended to the file!")

Step 1: The Append Tool

Let's add a new tool to obsidian_tools.py. This tool will allow the LLM to write new insights into the vault and link to existing notes.

Add the following code below your read_obsidian_note tool:

@tool
def append_obsidian_note(note_name: str, content: str) -> str:
    """Appends content to a local Obsidian note by its name. 
    If the note does not exist, it will be created.
    Do not include the .md extension in the note_name.
    To link to another note, use standard Obsidian wiki-link syntax in the content (e.g., [[Note Name]] or [[Note Name|Alias]])."""
    
    clean_name = note_name.replace("[[", "").replace("]]", "").replace(".md", "")
    file_path = VAULT_DIR / f"{clean_name}.md"
    
    # We use 'a' for append mode. It automatically creates the file if it doesn't exist.
    with file_path.open("a", encoding="utf-8") as f:
        # Add a couple of newlines before appending new content for readability
        f.write(f"\n\n{content}")
        
    return f"Successfully appended content to '{clean_name}'."
