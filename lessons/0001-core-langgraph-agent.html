The Core LangGraph Agent Loop

Welcome! Since you already understand how text splitters work, you know how to prepare documents for a vector database. But to make decisions, execute searches, and write notes, our agent needs a stateful execution loop. In LangChain, the modern standard for this is LangGraph.

Unlike simple linear chains, agents need to loop: they think, call a tool, inspect the result, and decide whether to call another tool or finish. LangGraph models this loop as a graph.

The Three Pillars of LangGraph

1. State (The Memory)

The state is a shared database (usually a Python dict or TypedDict) that gets passed from node to node. Every node can read from it and write updates to it. The state represents the current "mind" of the agent.

2. Nodes (The Actors)

Nodes are Python functions that perform actions. They take the current State as input, perform some computation (like calling an LLM or querying a database), and return a dictionary of updates to the state.

3. Edges (The Rules)

Edges connect the nodes. They define the path. There are two kinds of edges:

  • Normal Edges: Go from Node A to Node B directly (e.g., START to the agent node).
  • Conditional Edges: Go to different nodes depending on a function's output (e.g., deciding whether to go to the tools node or the END node depending on if the LLM called a tool).

The Classic ReAct Agent Architecture

For your Obsidian agent, we will start with a classic ReAct (Reason + Action) loop. It looks like this:

[START] → [Agent / LLM]
             ↓ (decides to call tool?)
       [Conditional Router] →(No)→ [END]
             ↓ (Yes)
         [Call Tool] →→→ (update state with tool result) →→→ [Agent / LLM]

A Minimal Code Template

Here is how you define a minimal state and graph structure in Python. Notice how we use add_messages to ensure message history is accumulated rather than overwritten:

from typing import Annotated
from typing_extensions import TypedDict
from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langchain_core.messages import BaseMessage

# 1. Define the State
class AgentState(TypedDict):
    # The list of messages in the conversation.
    # add_messages appends new messages to the existing list.
    messages: Annotated[list[BaseMessage], add_messages]

# 2. Create the Graph Builder
builder = StateGraph(AgentState)

# 3. Add Nodes (Placeholder functions for now)
def agent_node(state: AgentState):
    print("--- Agent Thinking ---")
    return {"messages": [{"role": "assistant", "content": "Hello! I am ready."}]}

builder.add_node("agent", agent_node)

# 4. Set Edges
builder.add_edge(START, "agent")
builder.add_edge("agent", END)

# 5. Compile the Graph
graph = builder.compile()
