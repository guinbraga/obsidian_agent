Reading Local Obsidian Notes

Welcome back! You've successfully built an agent that searches pgvector and the internet. Now it's time to build the defining feature of our project: interacting with your local Obsidian vault.

In this lesson, we will write a custom @tool that reads markdown files from a local directory, simulating an Obsidian vault. Later, we'll teach the agent to write links between them.

Pathlib for Local File Interaction

Python's pathlib module is the modern way to handle file paths. It's much cleaner than os.path and is perfect for searching through directories.

from pathlib import Path

# Define the vault path
vault_path = Path("./vault")

# Ensure the directory exists
vault_path.mkdir(exist_ok=True)

# List all markdown files
for note in vault_path.glob("*.md"):
    print(note.name)

Step 1: Create a Dummy Vault

Before we write the tool, let's create a dummy Obsidian vault with some notes to search.

  1. Create a folder named vault/ in your project root.
  2. Inside vault/, create a file called Agents.md: 
    # Agents
An agent is an AI system that can use tools to perform tasks.
See also: [[LangGraph]]
  3. Create another file called LangGraph.md: 
    # LangGraph
A framework for building stateful, multi-actor applications with LLMs.

Step 2: Defining the Read Tool

Now, let's write a tool that the LLM can use to read the contents of these notes. Create a new file called obsidian_tools.py:

from langchain_core.tools import tool
from pathlib import Path

VAULT_DIR = Path("./vault")

@tool
def read_obsidian_note(note_name: str) -> str:
    """Reads the content of a local Obsidian note by its name. 
    Do not include the .md extension in the note_name."""
    
    # Clean the note name in case the LLM passes brackets or extensions
    clean_name = note_name.replace("[[", "").replace("]]", "").replace(".md", "")
    file_path = VAULT_DIR / f"{clean_name}.md"
    
    if file_path.exists():
        return file_path.read_text(encoding="utf-8")
    else:
        return f"Error: Note '{clean_name}' not found in the vault."

Notice the docstring! We explicitly tell the LLM how to format the argument (no .md). The more precise the docstring, the fewer mistakes the LLM will make.

Checkpoint Quiz

Question: Why do we strip [[ and ]] in the tool's code rather than just telling the LLM not to use them?

Interactive Exercise

Let's test our new tool directly before giving it to the agent.

  1. At the bottom of obsidian_tools.py, add this test code: 
    if __name__ == "__main__":
    # Ensure vault exists
    VAULT_DIR.mkdir(exist_ok=True)
    
    # Test reading a note
    print("Testing read tool:")
    print(read_obsidian_note.invoke("Agents"))
    
    # Test error handling
    print("\nTesting missing note:")
    print(read_obsidian_note.invoke("NonExistentNote"))
  2. Run it: 
    python obsidian_tools.py
