The Complete ReAct Agent Loop

Your summary of Lesson 2 was 100% correct! Now that we know how to define tools and bind them to the LLM, we need to complete the feedback loop: actually executing the tools and passing the results back to the model.

In this lesson, we will introduce a Web Search tool, set up a tool execution node, and compile a fully functional ReAct (Reason + Action) agent loop.

Executing Tools: ToolNode

In LangGraph, we execute tools using a built-in helper called ToolNode from langgraph.prebuilt. It acts as a node in our graph: it reads the state's messages, finds the latest tool calls requested by the LLM, executes the corresponding python functions, and appends the tool results as new messages to the state.

Routing: tools_condition

To decide whether the agent should execute a tool or finish, we use a conditional edge. LangGraph provides a prebuilt helper called tools_condition. It inspects the LLM's response:

  • If the response contains tool calls, it routes the path to the tools node.
  • If the response is a normal text response, it routes the path to END (finishing the run).

Since we installed `duckduckgo-search`, we can define a web search tool without requiring any API keys:

Step 2: The Complete ReAct Graph Code

Here is the full Python script to assemble and run the agent. Note how the loop automatically bounces between agent and tools until the task is complete:

from typing import Annotated
from typing_extensions import TypedDict
from dotenv import load_dotenv
import os

from langgraph.graph import StateGraph, START, END
from langgraph.graph.message import add_messages
from langgraph.prebuilt import ToolNode, tools_condition
from langchain_openai import ChatOpenAI
from langchain_core.messages import BaseMessage

# Import the search_textbook tool we wrote in Lesson 2
from run_tool_check import search_textbook
from langchain_community.tools import DuckDuckGoSearchRun

load_dotenv()

# 1. State Definition
class AgentState(TypedDict):
    messages: Annotated[list[BaseMessage], add_messages]

# 2. Define Agent Node
api_key = os.getenv("OPENCODE_API_KEY")
llm = ChatOpenAI(
    base_url="https://opencode.ai/zen/go/v1",
    api_key=api_key,
    model="glm-5.2"
)

# Bind BOTH tools
tools = [search_textbook, DuckDuckGoSearchRun()]
llm_with_tools = llm.bind_tools(tools)

def agent_node(state: AgentState):
    response = llm_with_tools.invoke(state["messages"])
    return {"messages": [response]}

# 3. Create Graph
builder = StateGraph(AgentState)

# Add Nodes
builder.add_node("agent", agent_node)
builder.add_node("tools", ToolNode(tools)) # Built-in executor

# Add Edges
builder.add_edge(START, "agent")
# Conditional router: agent -> tools OR agent -> END
builder.add_conditional_edges("agent", tools_condition)
# Once tools execute, loop back to agent
builder.add_edge("tools", "agent")

# Compile
graph = builder.compile()

Interactive Exercise

Let's run a script that tests the full agent loop. We will create a script called run_react_agent.py.

  1. Create run_react_agent.py in your root directory.
  2. Add code to ask a question that requires BOTH tools (e.g. comparing textbook RAG details with current trends online): 
    # Example execution in run_react_agent.py
if __name__ == "__main__":
    query = "What is RAG? Check my textbook, then search the web to see what the current top framework is in 2026."
    print(f"Asking: {query}\n")
    
    events = graph.stream({"messages": [{"role": "user", "content": query}]})
    for event in events:
        for node_name, state in event.items():
            print(f"\n=== Node Completed: {node_name} ===")
            if "messages" in state:
                last_msg = state["messages"][-1]
                print(f"[{last_msg.type.upper()}]: {last_msg.content[:400]}")
  3. Run it: 
    python run_react_agent.py
